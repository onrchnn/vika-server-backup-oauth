Privacy Policy

Last updated: October 29, 2026

ViKA Server Backup is a private utility operated by its owner to transfer and manage server backup archives in the owner's personal Google Drive account. It is not offered as a public service.

Google Drive Access

The application uses the Google Drive API with the drive.file permission to create, access, manage, and delete files used by this application.

Data Usage

Google Drive access is used exclusively for automated server backup storage and retention. The application does not access unrelated Google Drive files.

Data Sharing

The application does not sell or share Google Drive data with advertisers or unrelated third parties. Backup files are stored in the owner's Google Drive account.

Data Retention

Backup archives are retained according to the owner's configured backup schedule and retention settings. Older backup archives may be automatically deleted as part of this process.

Security

Access to Google Drive is authorized through Google's OAuth 2.0 authentication system. Authentication credentials are not published on this website.

Contact

For questions about this application, please contact the application owner using the support email displayed on the Google OAuth consent screen.
