ViKA Server Backup

ViKA Server Backup is a private backup utility used to securely transfer server backup archives to the owner's Google Drive account.

Purpose

The application uses Google Drive API access exclusively to create, manage, and retain server backup files.

Access

This application is intended for personal use by its owner and is not offered as a public service.

Privacy

For information about how Google Drive data is accessed and handled, please see our Privacy Policy.
